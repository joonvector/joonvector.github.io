1. 수집하는 개인정보의 항목 및 수집 방법

Cosmic Striker(이하 "게임")는 사용자의 어떠한 개인 식별 정보(이름, 이메일, 전화번호, 기기 고유값, 위치 정보 등)도 수집하거나 외부 서버로 전송하지 않습니다.

  • 회원가입이나 별도의 사용자 계정 로그인이 필요하지 않은 오프라인 지향 싱글 플레이어 게임입니다.
  • 개인정보를 입력받거나 수집하는 기능이 일체 포함되어 있지 않습니다.

2. 게임 데이터의 저장 (로컬 저장소 사용)

게임 진행 상황(점수, 최고 레벨, 보유 골드, 격납고 업그레이드 단계, 훈장 달성도)은 오직 사용자의 스마트폰 기기 내부 저장소(Local Storage / Web Cache)에만 안전하게 저장됩니다.

  • 해당 데이터는 외부 서버나 제3자에게 전송되지 않습니다.
  • 앱을 삭제하거나 기기 데이터를 삭제할 경우 로컬 데이터는 함께 영구 파기됩니다.

3. 제3자 제공 및 외부 공개

수집하는 개인정보 자체가 존재하지 않으므로, 어떠한 경우에도 제3자에게 개인정보를 제공, 공유, 판매하지 않습니다.

4. 아동의 개인정보 보호

본 게임은 모든 연령층이 즐길 수 있는 비폭력적인 우주 아케이드 슈팅 게임이며, 만 13세 미만 아동의 개인정보를 수집하지 않습니다.

5. 문의처
